
# SkillSync AI – Smart Career Platform

## About
SkillSync AI is a smart career platform designed to help students and job seekers analyze their resumes, identify skill gaps, and prepare for career opportunities.

## Features
- Resume PDF text extraction
- Keyword-based skill detection
- Resume strength score
- Skill gap analysis based on job requirements
- Personalized learning roadmap
- Curated learning resources
- Job role recommendations
- Responsive user interface
- Dark mode support

## Technologies Used
- HTML
- CSS
- JavaScript
- PDF.js
- GitHub Pages
